# Fondant Queue Craft

A bakery puzzle game for iPhone where you read cake orders, build the matching cake, and submit before the ticket expires. 50 levels with increasing difficulty.

## Game Overview

- **Genre**: Puzzle / Time Management
- **Platform**: iPhone (Portrait only, iOS 15.0+)
- **Bundle ID**: com.rosewood.fondantqueuecraft.game
- **Version**: 1.0

## Core Mechanics

- 4 categories: Base (6 options), Cream (6 options), Filling (4 options), Decoration (5 options)
- Read order tickets and build a matching cake
- Tickets arrive on a timer and expire if not fulfilled
- 50 levels with progressive difficulty
